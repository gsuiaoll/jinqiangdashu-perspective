## 一、口播骨架（156 条通用公式）

几乎每条口播都走同一个骨架，写口播直接照套：

> **钩子（反常识断言 / 痛点 / 挑衅，0~3 秒）→ 数字框架展开（「第一第二第三」或「五层/三颗/三步」）→ 每个点配一个真实案例 → 强互动收尾（点个赞 / 点赞收藏 / 看到这还不点赞）。**

| 段 | 作用 | 高频做法 |
|----|------|---------|
| 钩子 | 前 3 秒留人 | 反常识断言「你的同情心就是你最大的漏洞」、挑衅「深圳的老板绝大多数都是胆小鬼」、自曝「耽误我发财的三颗绊脚石」 |
| 数字框架 | 给结构、制造收藏欲 | 「第一第二第三」「五层金字塔」「三颗绊脚石」「五种模型」「15321 五步工作流」——**观点必拆成 N 个** |
| 案例配点 | 让每个点有画面 | 每个观点绑一个真实案例：BOSS直聘、小罐茶、一颗大番茄、香港 OfferToday、王石、吕不韦、自己北漂 17 次家 |
| 互动收尾 | 拉完播、涨粉 | 「点个赞」「点赞收藏」「看到这你还不点赞」「你点个赞我继续」 |

**关键启示**：口播不是「讲一个观点」，是「把观点拆成 N 个 + 每个配案例 + 结尾求赞」。数字框架是留人和收藏的第一武器。

## 五、15321 五步工作流（首度公开的方法论，值得单独记）

他公开的公司工作流（以「小琴海参」为例）：

1. **先找 100 个垃圾**：先列 100 个以上可能性，不考虑用户市场，把 4P、情绪价值、借势、卖点堆叠全部捋一遍。
2. **5 种纠结**：选出 5 个方向，**每个方向必须做出成品/演示**，不能只纸上谈兵（战略公司的通病就是方案好、制作不在手上、导演只想拿奖）。
3. **3 个试探**：做 3 个测试素材给客户看，让客户「沉淀两周再选」；最猛的创意往往最不考虑公关风险，要风险管控。
4. **2 个退路**：出两个版本，考虑投放地区特点，选「最合适的」而非「传播最强的」。
5. **1 个答案**：复杂的问题简单化 → 简单的问题粗暴化 → 粗暴的问题科学化 → 科学的问题艺术化。

> 用法：写方案/文案时，先发散 100 个、收敛到 5 个、测试 3 个、留 2 个退路、定 1 个答案。

## 八、给文案生产的直接启示（写入工作流）

1. **口播永不平铺**：一律「钩子 → 数字框架 → 案例 → 求赞」四段。
2. **观点必须拆成 N 个**：一个观点讲 30 秒不如拆成「三点」讲 30 秒，数字框架是收藏率关键。
3. **每个点绑一个真实案例**：没有案例的金句是空的，案例越具体（品牌名、数字、人物）越有画面。
4. **结尾必带互动指令**：「点个赞 / 点赞收藏」，不是可选项。
5. **To C 用挑衅，To B 用算账**：挑衅句式只对 C 端；B 端戳「采购省钱老板买单」。
6. **自曝是流量**：个人 IP 文案优先挖真实「事故」，别写成功学。
7. **借历史人物讲营销**：孔子=矩阵、诸葛亮=饥饿营销、范蠡=流量变现、吕不韦=跨界 IP、王阳明=心智营销——把抽象方法论套进耳熟能详的人物，是最强的「借势」。
8. **先发散再收敛**：100 个垃圾 → 5 个方向 → 3 个测试 → 2 个退路 → 1 个答案。
9. **To B 用算账，To C 用挑衅**：B 端戳「采购省钱、老板买单、渠道有钱赚」；C 端戳「怕丑、怕死、怕穷、怕错过」。
10. **借历史人物／电影讲营销**：西游记讲战略、周星驰讲人生阶段、槟榔讲渠道利润、法拉利讲高端定价——把抽象方法论套进耳熟能详的人事物，是最强借势。
11. **数字框架 + 三流合一**：观点拆成 N 点；B 端文案可套「心流（让人忘不掉）→ 物流（渠道铺满）→ 节流（抢人心抢未来）」三段。

## 九、深度方法论补充（第 69~156 条精读新增）

这些是后半部分口播里反复出现、可独立成篇的核心框架，写文案时可直接套用：

### 9.1 三种 IP 模型（决定你能赚哪种钱）
复读机 IP（搬运，最安全但上限低，99% 的人困在这里）→ 故事型 IP（搞情绪搞共鸣，赚快钱，天花板是情绪反噬）→ 理论发明者 IP（开宗立派，吃「供奉钱」＝一辈子的认知税，钱会主动上门）。**钩子**：「你以为你在奋斗，其实你在监狱里原地踏步。」「每个人天生就是一个 IP。」

### 9.2 三流合一（B 端／品牌的核心打法）
买的是「心流、物流、节流」三流合一，不是人流。
- 心流：不是让你看见，是让你忘不掉；看不见的流量最值钱（卫龙魔芋爽「热量低了爽多了」年营收 72 亿）。
- 物流：渠道铺满，对手连露面的机会都没有（卫龙 80 万终端，线上只占 10%）。
- 节流：先你一步抢心智、抢标准、抢人心，堵死对手所有退路。
**金句**：小老板买人流，大老板买心流；小公司抢订单，大公司建城墙。

### 9.3 利润设计者（被分配者 vs 设计者）
努力是被分配者的标配，设计是设计者的特权。谁设计游戏谁掌握分配权，谁参与游戏谁拿劳务费。普通人的痛苦 99% 来自「在别人的游戏里试图赢过别人」。
- 五条利他思维：①解决痛苦越大利润越大（痛苦是商业第一性原理）②让人省力＝流量入口 ③给希望＝终身价值 ④成就别人成就系统 ⑤降低社会成本，社会奖励你巨额财富。
- 落地五步：封装可复制产品 → 只服务一类人一个痛点 → 设计自动运转流程 → 搭利他分配机制 → 不断升级规则（不升级装备）。

### 9.4 开宗立派十步（造一套理论）
①向时代揭示集体痛苦（没有痛苦就不需要学术）→ ②给痛苦统一归因（怪天怪地不怪自己）→ ③主客观认知切换（痛苦＝主观强行对抗客观）→ ④创造外部最高力量 → ⑤设计日常修行行为 → ⑥构建善恶价值体系 → ⑦设定终极归宿消除死亡恐惧 → ⑧语言模棱两可（越具体越易被挑战）→ ⑨关键词适配时代包装 → ⑩自我复制自动裂变。
**金句**：人性永远有缺口，缺口就是痛苦，痛苦就是刚需，刚需就是流量、信徒。剥开所有高尚外壳，里面只有四个字：解决痛苦。三个大坑：把自己的痛苦当全世界的痛苦、看不起世俗痛苦故弄玄虚、只看表面痛苦不挖根源。

### 9.5 找到需求 → 放大需求 → 包装需求（三步卖货）
先想清挣谁的钱（把怕丑卖给女性，把怕死卖给老人，把梦想卖给老板）→ 放大需求（小米放大科技属性）→ 包装需求（「为发烧而生」，二次元／艺术的名义包装真实需求）。**金句**：女神只有变成女神经，才会获取女性用户。

### 9.6 取名／改名哲学（科学＋玄学）
改名就是改命，名字是最短的咒语。名字自带气场，气场自带流量，流量自带声音。科学解决「能不能用」（好记好读好搜好注册），玄学解决「顺不顺、强不强、大不大」。**案例**：一颗大番茄（500 万起名，黑红也是红）——「先出圈，别考虑那么多」。

### 9.7 钓大客户三原则（To B 谈单）
小客户给点利润就上钩，大客户只认真东西。钓大客户：①去有大鱼的地方（深水区，不是小河沟）②去普通人去不了的地方 ③给真东西——80% 真 20% 假，真东西里带钩子。

### 9.8 打嘴炮五步（普通人破局武器）
别讲道理只讲气势 → 不要脸面只管输出 → 直击痛处不绕弯子 → 不讲斯文只讲痛快 → 打完就走绝不恋战。**金句**：嘴炮一响，黄金万两；嘴炮是穷人的核武器。

### 9.9 懂战略（西游记三句话）
天天打妖怪叫干活，一心去西天取经才叫战略。方向定死、路线走死、信念咬死，向死而生。你想挣钱，那你就得当孙子；你想走到终点，就不能半路散伙。

### 9.10 懂事（东方哲学）
你混不好，是因为你不懂事。懂事是打透中国人内心的底层密码，判断一个人能不能用就看懂不懂事。送的不是礼品，是懂事。

### 9.11 摆烂是一种策略
水往低处走，积水成潭。风口像皮鞭把羊群往羊圈里赶，绷太紧会断。每次摆烂都是充满电归来。

### 9.12 高端品牌拼耐心
低端品牌拼速度，高端品牌拼耐心。当你定好一个价格，就是你品牌实力的总和。屈尊迎合不喜欢你的人没有任何必要，你只要等待财富转移后的第一批受益者出现。
