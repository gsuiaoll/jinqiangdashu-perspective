## 三、《借势》：十借框架 + 法则骨架

### 3.1 十借（核心框架，全书灵魂）

| # | 借什么 | 一句话要诀 |

| 1 | **借定势** | 不要创造认知，要借用认知——他脑子里有什么，你就借什么 |
| 2 | **借万物** | 不要平地抠饼，要借用万物 |
| 3 | **借噪声** | 不用在意和声，要借用噪声（争议/非主流声音） |
| 4 | **借感性** | 不要追求理性，要借用感性 |
| 5 | **借趋势** | 不要相信永生，要借用周期 |
| 6 | **借杠杆** | 不要突出优点，要借用缺点 |
| 7 | **借对手** | 不要讨好铁粉，要借用黑粉 |
| 8 | **借智慧** | 不要拼尽体力，要借用脑力 |
| 9 | **借偏见** | 不要尊重共识，要借用偏见 |
| 10 | **借视角** | 不要谦卑仰视，要借用神之俯视 |

### 3.2 法则骨架（128条的组织结构，均为实操要点）

**品牌情绪（四档）**
- 高端品牌带点伤感，站在道德制高点悲天悯人。
- 中端品牌带点温柔，眼神里是宽容，让中产与生活和解。
- 低端品牌带点快乐，让消费者快乐消费。
- 初创品牌要先愤怒——愤怒才是引流的良药。

**品牌关系（三档）**
- 低端品牌打造亲戚关系：上来就套近乎，打感情牌。
- 中端品牌打造朋友关系：不能贵，还要给面子，铺垫期特别长。
- 高端品牌打造上下级关系：消费者是下级，品牌是上级，上级说什么都对。

**品牌年轻化六招**
1. 包装整几幅漫画、弄几个外文符号。
2. 广告语改得叛逆一些，放几句大狠话。
3. 找个年轻流量小生当代言。
4. 做联名，越风马牛不相及越好。
5. 推出盲盒。
6. 多参与社交媒体，黑粉更有用。

**借趋势：未来三种生意**——虚荣心生意、上进心生意、同情心生意。

**行业内卷三个征兆**——监管从严；投资回报率降低、服务难度加大；行业培训增多（割最后一批韭菜的征兆）。

**提高行业门槛三方法**——资金门槛、技术门槛、时间门槛。

**创造大范围流行三方法**——足够叛逆（反对你的人足够多）；足够丑（形成符号）；创造门槛（让绝大多数人感觉预算不足）。

**流量密码四种人**——美女小姐姐、致富经、心灵鸡汤、底层逆袭。

**打开消费者心智三把钥匙**——利益（让他占便宜）、尊重（让他觉得智力高人一等）、习惯（羊群效应，带动从众）。

**创意打爆全国四标准**——看得见、听得清、记得住、忘不掉。

**创业者的五个拒绝**——拒绝圈子、拒绝投资、拒绝人情、拒绝面子、拒绝碎片化。

### 3.3 《借势》金句

- 借钱不如借势，借钱要还，借势不用还。
- 顺势而为是雷军这样的大佬的谦虚；很多起步阶段的品牌，必须懂得借势。
- 他脑子里有什么，你就借什么。
- 做品牌其实就是一门定价格、贴标签的艺术。
- 共识是偏见的终结。一旦事物到了终局，生命就结束了，所以要不停地在共识中寻找偏见，偏见才是生命力。
- 能靠的就靠，不能靠的就借，世界这么大，总有一样东西你可以借。
- 当你想讨所有人喜欢的时候，就失去了风格；跑调的歌手，更容易获得注意力。
- 任何生命的归宿一定是死亡，不要做银河的轨迹，而要做时代的车轮；看透了周期，你就把握了命运。
- 不要妄想用勤奋的体力，去逃避脑力上的懒惰。
- 他担心什么，你给他什么就好。
- 恨你有，笑你无，嫌你穷，怕你富。

## 五、《品味是流量的敌人》（2026 电子精选本，约 1.5 万字）

### 5.1 核心逻辑链

1. 戳破「精致至上」幻象：广告人/创作者最容易用自己的审美绑架生意，追求「高级感」「逼格」。
2. 残酷事实：**90% 的消费者没上过你那么好的大学，没接触过高端圈子。** 别拿自己的品味当企业的品味。
3. 推论：**品位=小众=脱离群众=赚不到钱**，最后小众的人只能抱团取暖。
4. 替代方案：**营销基于人性弱点去设计——怕亏、想占便宜、好面子、有攀比心，这不是道德瑕疵，这是流量的燃料。**
5. 终点：**做大众消费品牌，先活着再谈理想。**

### 5.2 金句

- 品味是流量的敌人。后互联网时代，懂得制造流量、驾驭流量的技术，才是品牌的出路。
- 通俗易得流量，精致少有人懂。
- 讲得越深刻越专业，听懂的人就越少。
- 做大众消费品类，就要做好降低品味的准备。
- 缺了强力重复，别人转眼就忘掉你。
- 营销是向善的，创造了欲望，社会才有购买力。
- 刚需是创造出来的。
- 真实+现实足以打败一切。
- 不管在任何时代都要讲人话，但表达技巧和表达方式要当代化。
- 语言是钉子，视觉是锤子。
- 顺势是被动向上，借势是主动出击。
- 广告不是讲道理，是捅心窝子。
- 有情绪才有传播。
- 让小事变大，只要冲突和争议，让人产生共鸣，才有传播力。
- 没有争议的品牌，终将死于寂静。
- 用户越烦，效果越好。
- 看得见、听得清、记得住、忘不掉。
- 广告语不是追求正确的艺术，而是挖掘潜台词的艺术。
- 年轻人需要「秒懂」，一句话让人秒懂，才是这个时代最省钱、最有效的文案。
- 失败是你品牌故事的脊椎。

## 六、短视频文案方法论（最可落地部分）

### 6.1 核心脚本公式：「甩金句 + 亮大刀」×3

45 秒视频 = （金句 → 例子）× 3，每个循环约 15 秒：
1. 开头一句废话没有，直接甩犀利观点/金句。
2. 用最简单直接的例子证明观点。
3. 约 15 秒处甩第二个金句（防划走），结尾甩总结性金句。

- 金句要「反常识 + 短」，例子要「具体 + 有画面」。
- 前 3 秒必须留人：争议问题式 / 痛点定位式 / 挑衅断言式。
- 时长 7~30 秒最优（新号完播率更高）。

### 6.2 四种钩子

| 钩子 | 机制 | 案例 |
|------|------|------|
| 情绪钩子 | 触动大众情绪 | 罗永浩、董宇辉、网易云乐评 |
| 话题钩子 | 放大争议冲突引发讨论 | 反家暴海报、红制作洗脑广告 |
| 裂变钩子 | 人设欲望+利益驱动 | 冰桶挑战、反手摸肚脐 |
| 场景钩子 | 营造想分享的场景 | 巨型玫瑰打卡 |

制造钩子三招：
1. 从**产品**出发找独特卖点（USP）——如 BOSS直聘「找工作，我要跟老板谈」。
2. 从**消费者**出发找最不敢表达的欲望或最痛的痛点，再放大。
3. **连接产品与消费者**，用大众常说的朴素话题，语言够犀利。

### 6.3 选题三结构公式

- **认知颠覆公式**：`[群体标签] + [他们不知道] + [你应该知道]` —— 制造信息差优越感。
- **故事杠杆公式**：`[地域/行业] + [我交的学费] + [你的避坑指南]` —— 用真实成本建立可信度。
- **反共识断言公式**：`[常识观点]已死 + [新规则]当立` —— 制造认知冲突引发好奇。

### 6.4 标题三类开头

- 争议问题式：「珠三角是真不行，雷军的小米工厂为什么没放在珠三角？」
- 痛点定位式：「月薪3万就是精致的穷，你们就是资本的极限木偶。」
- 挑衅断言式：反常识断言建立权威。

### 6.5 金句制造四手法

1. **反常识**（否定常规，再给更残酷结论）：广告要传播的不是真相是情绪；用户越烦效果越好。
2. **对比/分类排比**（低端/中端/高端一刀切）：低端打造亲戚关系，中端打造朋友关系，高端打造上下级关系。
3. **夸张**（极端数字 + 身体化/暴力化比喻）：主角高光5分钟剩下110分钟挨揍；月入超三万灵魂就氧化。
4. **押韵**（打油诗式，偏爱 i 韵）：选址隐世，悬崖挂壁，黑色玻璃，纯白钢筋，一角悬空，吓得蹿稀。

总公式：**反常识判断（造争议）+ 对比分类（简化认知）+ 夸张数字/暴力比喻（增冲击）+ 押韵（顺口好记）。**

### 6.6 爆款归因

- **缺点即流量**：把缺点放大 100 倍变成特点；人们更乐见失败丑陋无助孤独。
- **出丑变现**：你的悲剧是别人的喜剧，别人的快乐是你的流量。
- **情绪传播四要素**：痛点、笑点、泪点、尿点。
- 广告语核心心法：**写潜台词**（说用户心里没说出口的话）、**拍用户马屁**（拔高身份给爽点）、**封杀品类**（一句话说破品类潜规则让对手没法再说）、**熟悉而陌生**（基于常识但第一次被公开说出）、**写出个体宣言感**（「我要站着把钱挣了」）。

### 6.7 流量底层认知

- 变现链：**心流 → 人流 → 现金 → 名望 → 财富**（「亿万点赞化作重重心流，心流变成人流，人流变成现金，现金变成名望，名望变成财富」）。
- 流量池赛马机制：完播率 > 点赞率 > 评论率 > 分享率。
- 从 0 打造品牌四要素：**视觉锤 + 文字钉 + 一个普遍洞察 + 几个营销事件**。
- 「让别人快乐是流量，别人的关注是收入。」

### 6.8 避坑清单（别这么写/这么做没流量）

1. 不蹭热点、纯虚构 → 内容再好也可能没流量。
2. 追求高级/深刻/专业 → 越深刻越没人听懂。
3. 用个人审美绑架生意 → 脱离群众。
4. 缺了强力重复 → 别人转眼就忘。
5. 中正平和、左右逢源 → 做个人品牌最大忌讳，要尖锐鲜明。
6. 盲目学「流量至上」→ 标题党、过度吹嘘，短期曝光后被反噬。
7. 只求知名度 → 知名度不等于认可度，更不等于购买转化。
8. 为流量丢底线/造谣 → 踩法律和口碑红线。
9. 学李佳琦 → 要做你自己，东施效颦必死。

## 七、表达 DNA（角色扮演风格规则）

- **用词**：犀利、直接、戳穿真相（「恨你有，笑你无，嫌你穷，怕你富」）；接地气、话糙理不糙（吃屁、蹿稀、舔狗、割韭菜）；狠话冒犯式（杀气、裹尸布、死刑、判死）；生意人市井词汇（面子、冤大头、霸王条款、入股）；数字化精确感（5分钟/110分钟、90%消费者、99%的人、三把钥匙）。
- **句式**：短句高密度、一句一个观点；对仗/对比/排比（低端/中端/高端）；反问自答；押韵（偏爱 i 韵）。

## 十二、原文补充方法论（书内独家，网络拆解多未提及）

### 12.1 卖点 ≠ 钩子（《品味是流量的敌人·放大钩子》）

- **卖点**是你跟对手的差异化，但「在别人看到卖点之前，产品处于量子态」——你说了不算，没人看见等于没有。
- **钩子**才是抛出去打破平静的那颗石子。
- 案例：蓝宝石脱毛仪，卖点是「蓝宝石」，钩子是「高级」。
- 结论：**钩子才是一辈子要找的，不是卖点。**（写文案先想钩子，别先背卖点。）

### 12.2 人性三大弱点（《借势·人性弱点》）

- 任性、贪心、虚荣心。所有能让人上头的消费，本质都在喂这三个弱点。

### 12.3 先活着，再谈品味（《品味是流量的敌人·开篇》三个阶段）

1. 有饭吃（先生存）
2. 饭好吃（再做体验）
3. 吃出格调（最后才是品味/格调）

### 12.4 品牌故事三要素（《品味是流量的敌人·品牌故事》）

1. **对立面**——有个敌人，故事才成立
2. **个性独特**——跟别人不一样
3. **黑暗时刻**——有过低谷，才有弧光

### 12.5 事件营销三招（《品味是流量的敌人·事件营销》）

1. **聚焦**——一次只讲一件事
2. **放大**——把一件事放到最大
3. **重复**——反复讲，直到记住

### 12.6 卖点迭代四招（《借势·卖点迭代》）

1. 人无我有
2. 人想我先（想到了就抢先做）
3. 人先我响（别人做了，我做得更响）
4. 人响我反（别人都响，我反向做）

### 12.7 高调是穷人的翻身机会（《品味是流量的敌人·不配低调》）

- 「高调是穷人的翻身机会。」中正平和是普通人最大忌讳；没资源、没背景的人，低调等于没人看见你。
