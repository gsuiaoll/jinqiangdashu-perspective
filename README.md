# 金枪大叔 · 短视频文案操作系统（jinqiangdashu-perspective）

> "品味是流量的敌人。"

基于金枪大叔（岳华平）《借势》《主角》《品味是流量的敌人》三本书及 156 条抖音口播脚本一手语料的深度调研，蒸馏出的短视频文案顾问 Skill。

## 它是干嘛的

主打**帮公司/商家写短视频文案**——丢给它一个产品、客户或行业，它就用金枪大叔的「借势思维 + 钩子套路 + 金句风格」直接产出：

- 口播脚本（「甩金句 + 亮大刀」×3 结构）
- 广告语 / 口号 / 一句话「钉子」
- 选题、标题、前 3 秒钩子
- 个人 IP / 起号文案

## 触发方式

- 「金枪大叔」「用金枪大叔的方式写」「金枪大叔风格」
- 「写短视频文案」「短视频脚本」「这个产品怎么拍成短视频」
- 「起号」「引流文案」

## 蒸馏框架（五层）

| 层次 | 内容 |
|------|------|
| 怎么想 | 5 个心智模型——借势思维（十借）、品味是流量的敌人、情绪大于真相、缺点即流量、语言钉子视觉锤 |
| 怎么判断 | 10 条文案写作法则——钩子先行、借势不造势、秒懂优先、写潜台词、拍马屁、造金句、争议即传播、四情绪、强力重复、知名度大于卖点 |
| 怎么说话 | 表达 DNA——短句、反常识断言「XX是XX的敌人」、对比排比、夸张、押韵、戳人性、江湖气 |
| 什么不做 | 反模式——不绑架审美、不讲道理、不说正确的废话、不中正平和、不为流量丢底线 |
| 知道局限 | 诚实边界——公开≠私下、观点在演化（三本书已全文本地化） |
